## 写作边界

推荐表述：

> RaysTwins 可作为教学辅助仿真平台，用于支撑数字孪生场景构建、任务包配置、仿真执行、训练推理、回放评估等实践环节。

禁止表述：

- 本教材完全基于 RaysTwins。
- RaysTwins 替代所有主流仿真平台。
- RaysTwins 是唯一选择。
- RaysTwins 已支持某某 API，除非资料明确给出。
