# 附录 D 术语表

> 骨架。术语的权威定义以 `metadata/terminology.yaml` 为准，本附录是其面向学生的可读版。
> 写作时应与 terminology.yaml 保持一致，避免中英文术语混用。

| 术语 | 英文 | 一句话说明 |
|---|---|---|
| 具身智能 | Embodied AI | 在身体、环境与任务约束中通过感知—规划—行动—反馈实现智能行为。 |
| 具身智能体 | Embodied Agent | 在环境中感知、决策并通过动作影响环境的主体。 |
| 感知—规划—行动—反馈闭环 | Perception-Planning-Action-Feedback Loop | 具身系统的基本运行闭环。 |
| 数字孪生 | Digital Twin | 对现实对象/环境/过程的数字化建模与状态映射。 |
| 仿真平台 | Simulation Platform | 提供物理、渲染、传感器与评测环境的软件系统。 |
| 任务包 | Task Package | 描述实验任务的结构化材料（场景、目标、约束、指标等）。 |
| 回放评估 | Replay and Evaluation | 对执行过程记录、回放、计算指标与分析。 |
| Sim2Real | Simulation to Reality | 将仿真中开发的策略迁移到真实环境。 |

> 其余术语（LLM、VLM、VLA 等）请同步补全，并保持与 terminology.yaml 一致。
