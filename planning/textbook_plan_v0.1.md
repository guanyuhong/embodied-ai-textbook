# 《具身智能导论：从数字孪生仿真到智能体实践》高校教材编写方案

> 版本：v0.1  
> 用途：供 Codex 后续生成教材初稿、章节样稿、实验手册、课程大纲与配套资料使用。  
> 定位：面向高校人工智能、机器人工程、自动化、智能制造、数字孪生等专业的具身智能基础教材。  
> 核心原则：具身智能通用能力为主，RaysTwins 作为教学辅助仿真平台之一。

---

## 1. 教材定位

### 1.1 教材名称

**《具身智能导论：从数字孪生仿真到智能体实践》**

建议副标题：

**面向高校人工智能与机器人专业的基础教材**

或：

**面向高校的具身智能系统与仿真实践教材**

### 1.2 教材属性

本教材不是企业产品白皮书，不是 RaysTwins 平台培训手册，也不是单纯的机器人学教材，而是一门面向高校教学的综合型具身智能教材。

教材主线是：

```text
具身智能基础概念
  ↓
感知—规划—行动—反馈闭环
  ↓
机器人系统、任务建模与环境交互
  ↓
导航、操作、控制、学习与智能体
  ↓
数字孪生仿真、评测、回放与 Sim2Real
  ↓
综合项目实践
```

### 1.3 RaysTwins 的角色

RaysTwins 在本教材中定位为：

> 教学辅助仿真平台 / 国产化具身仿真后端 / MuJoCo、PyBullet、Isaac Sim、Isaac Lab、Habitat、ManiSkill 等平台的可选替代或补充。

表达边界：

```text
不要写成：本教材基于 RaysTwins 平台。

建议写成：本教材以具身智能通用理论与系统实践为主线，选取 RaysTwins 作为教学辅助仿真平台之一，用于支撑数字孪生场景构建、任务包配置、仿真执行、训练推理、回放评估与课程项目实践。
```

一句话原则：

> 教材讲的是具身智能，RaysTwins 提供实验场。

---

## 2. 面向对象与课程规格

### 2.1 适用专业

本教材适用于以下高校专业或方向：

- 人工智能
- 智能科学与技术
- 计算机科学与技术
- 机器人工程
- 自动化
- 智能制造工程
- 数字孪生工程
- 虚拟现实与数字媒体技术
- 新工科交叉实验班
- 人工智能微专业 / 机器人工程微专业

### 2.2 适用层次

- 本科高年级专业课
- 应用型本科专业方向课
- 高校人工智能微专业课程
- 机器人、自动化、智能制造方向选修课
- 研究生导论课或工程实践课

### 2.3 先修课程建议

建议学生具备：

- Python 程序设计基础
- 人工智能导论
- 机器学习基础
- 线性代数与概率统计基础
- 计算机视觉基础，建议但不强制
- 机器人学或控制基础，建议但不强制

### 2.4 推荐课程规格

建议设置为：

```text
课程名称：具身智能导论
学分：3 学分
总学时：48 学时
周期：16 周，每周 3 学时
课程类型：专业选修课 / 专业方向必修课 / 微专业核心课
```

建议学时结构：

| 类型 | 学时 | 说明 |
|---|---:|---|
| 理论讲授 | 30 | 具身智能基础、感知、规划、控制、学习、智能体、仿真 |
| 实验实训 | 12 | Python 轻量实验 + 仿真平台实验 |
| 项目开发 | 4 | 小组综合项目开发与调试 |
| 展示答辩 | 2 | 项目汇报、演示、复盘 |
| 合计 | 48 | 一学期完整课程 |

## 3. 教材内容比例

为避免教材变成产品说明书，建议控制内容比例：

| 内容类型 | 建议比例 | 说明 |
|---|---:|---|
| 具身智能基础理论 | 35% | 概念、系统架构、机器人基础、任务建模 |
| 感知、规划、行动与学习 | 30% | 视觉、导航、操作、强化学习、模仿学习 |
| 大模型与智能体 | 15% | LLM、VLM、VLA、任务规划、工具调用 |
| 数字孪生与仿真平台 | 15% | MuJoCo、PyBullet、Isaac、Habitat、ManiSkill、RaysTwins |
| RaysTwins 教学案例 | 5%–10% | 作为教学辅助实验平台，不作为唯一主线 |

核心写作原则：

```text
80% 讲通用能力，20% 做平台实践。
```
