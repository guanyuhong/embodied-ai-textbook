# 文笔与文风规范

本规范用于统一教材正文、实验指导和审计意见的语言风格。

## 1. 基本口吻

- 使用高校教材口吻：准确、清晰、克制。
- 先定义概念，再解释机制，再给例子，最后说明边界。
- 少用宣传式形容词，不使用“全球领先”“颠覆性”“唯一”“最强”等表达。
- 不把 RaysTwins 写成产品宣传、平台培训手册或唯一实验环境。

## 2. 段落风格

- 每段聚焦一个教学点，避免多个概念堆在一个长段中。
- 导论章段落应短而清楚，帮助学生建立问题意识。
- 技术章节可适当增加公式、表格和过程说明，但应先解释符号含义。
- 平台段落应服务教学目标，不展开无资料支撑的操作细节。

## 3. 定义框

首次引入关键概念时，优先使用定义框。

```markdown
> **定义 1-1 具身智能**  
> 具身智能是指智能体依托物理或虚拟身体，在环境约束和任务目标下，通过感知、规划、行动与反馈形成闭环，并在交互过程中表现出适应性行为的人工智能形态。
```

要求：

- 编号按章节递增：`定义 1-1`、`定义 1-2`。
- 定义应短，后文再展开解释。
- 定义不夹带平台宣传。

## 4. 例子框

概念抽象时，应使用例子框帮助学生理解。

```markdown
> **例 1-1 校园导览机器人**  
> 当校园导览机器人接到“请带访客去人工智能实验室”的指令时，它需要定位当前位置、识别可通行区域、规划路线、控制底盘移动、避开行人，并在道路阻塞时重新规划。
```

## 5. 概念辨析框

容易混淆的概念必须显式辨析。

```markdown
> **概念辨析 1-1 具身智能、机器人与 AI Agent**  
> 机器人强调传感器、执行器和物理结构；AI Agent 强调目标驱动的任务拆解、工具调用和多步执行；具身智能强调智能体在身体和环境约束下完成连续交互。
```

## 6. 术语中英对照

- 首次出现英文术语时使用“中文（English）”或“English（中文）”。
- 后文优先使用中文术语，必要时保留英文缩写。
- 术语以 `metadata/terminology.yaml` 为准；缺失术语先补术语表或标注需人工确认。

## 7. 表格与题目

- 表格前后应有解释，不让表格孤立出现。
- 表题使用“表 X-Y 标题”，图题使用“图 X-Y 标题”。
- 思考题按层次组织：基础理解题、概念辨析题、应用分析题、拓展讨论题。
